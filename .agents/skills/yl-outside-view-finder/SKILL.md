# Outside-View Finder

## Inputs
Accept a defined target event or quantity, unit, population, horizon, geography, and any candidate comparable cases or source materials.

## Procedure
1. Define the target outcome before searching. State its denominator, measurement window, and inclusion rules.
2. Propose a broad reference class using criteria set before seeing favorable cases. Then consider narrower classes and explain the selection tradeoff.
3. For each candidate, record source and exact location, outcome, date, similarity, differences, and whether the outcome is known. Do not include an unknown outcome in numerical base-rate calculations.
4. Look for survivorship, selection, changing market conditions, correlated examples, and duplicated reports of the same case.
5. If a defensible base rate is possible, report numerator, denominator, unit, time period, and uncertainty. If not, provide qualitative context and the data needed to estimate one.
6. Invite the user to explain whether case-specific evidence warrants an adjustment; keep any adjustment separate from the observed base rate.

## Output
Return the reference-class definition; a case table; observed distribution or rate only when supported; exclusions; applicability limits; proposed next data collection. Mark provisional examples as unverified.

## Guardrails
Do not cherry-pick analogs to fit a preferred forecast. Do not convert a small convenience sample into a calibrated prior. Do not confuse sales, shipments, installed base, and demand.

## Trial case
For a novel foldable-phone launch, compare several relevant launches, reject incompatible measures, and state when no reliable unit-demand base rate can be derived.
